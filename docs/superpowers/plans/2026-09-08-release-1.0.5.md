# 1.0.5 发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 `io.github.zusrsoft:diagram-{core,layout,parser,render}:1.0.5`，落地"作者 huarangmeng / 维护者 zusrsoft"署名叙事（README + LICENSE），POM 不动。

**Architecture:** 纯元数据/文档发布：新建 LICENSE、双语 README 署名段与版本引用、VERSION=1.0.5、Gradle wrapper 统一 9.7.1、发布手册入库；随后按 1.0.4 实战手册走 allTests 回归 → MavenLocal 预演 → Central 正式发布 → 验证 → tag。

**Tech Stack:** Gradle 9.7.1 (KMP), vanniktech maven-publish 0.36.0, Sonatype Central Portal。

**执行环境说明：** 本计划在当前工作区（master）直接执行——工作区里未提交的 wrapper 9.7.1 改动是本次发布的一部分，不开独立 worktree。

**依据文档：**
- 设计：`docs/superpowers/specs/2026-09-08-release-1.0.5-design.md`
- 发布手册：`MAVEN_CENTRAL_PUBLISH.md`（命令、凭证、踩坑对照）

- [ ] **Step 2: Portal 状态确认**

Run（手册 §7.2 脚本，凭证只在本机读取）：

```powershell
$props = @{}; Get-Content "D:\Dev-tools\gradle-repository\gradle.properties" |
  ForEach-Object { if ($_ -match '^([^#]\S+?)\s*=\s*(.*)$') { $props[$Matches[1]] = $Matches[2] } }
$pair = $props['mavenCentralUsername'] + [char]58 + $props['mavenCentralPassword']
$auth = "Basic " + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
$dep = Invoke-RestMethod -Uri "https://central.sonatype.com/api/v1/publisher/deployments" -Headers @{Authorization=$auth}
$dep.deployments | Select-Object deploymentName, deploymentState | Format-Table -AutoSize
```

Expected: 最新 deployment 的 `deploymentState` = `PUBLISHED`。状态 API 偶发 500 时重试（手册 §6.8）。
