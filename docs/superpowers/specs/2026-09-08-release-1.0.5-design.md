# 1.0.5 发布设计（署名叙事修正版）

> 状态：已与用户确认
> 日期：2026-09-08
> 发布目标：Sonatype Central Portal（`io.github.zusrsoft` 命名空间）

## 1. 背景与动机

- 仓库已完成坐标迁移（`io.github.huarangmeng` → `io.github.zusrsoft`），并在 2026-09-06 以新坐标重新发布了 1.0.4。
- 已发布的 1.0.4 POM 中 developers 仅含 zusrsoft，生态侧（Maven Central / MvnRepository / 搜索引擎）看不到与原作者 huarangmeng 的关系。
- 仓库根目录缺失 LICENSE 文件（POM 声明了 MIT，但无实际文本）。
- 需要一次发布把署名叙事补全：**作者 huarangmeng / 维护者 zusrsoft**。

## 2. 关键决策（用户拍板）

| 决策 | 结论 |
|---|---|
| POM developers | **维持仅 zusrsoft，不改**（四模块 `build.gradle.kts` 零改动，description 也不动） |
| 署名叙事载体 | README.md / README_zh.md 文案 + LICENSE 版权文案 |
| 版本号 | 1.0.5（plantuml activity 三个修复已随 1.0.4 发布，本次无代码变更） |
| gradle wrapper | 还原 9.3.1（丢弃本地 9.7.1 未提交改动，与 1.0.4 构建环境一致） |
| 发布通道 | 本地命令行（1.0.4 实战验证链路，凭证五项已在 GRADLE_USER_HOME 就绪） |
| `MAVEN_CENTRAL_PUBLISH.md` | 纳入版本控制（1.0.4 发布实战手册） |

## 4. 发布流程

1. 应用变更清单，`git status` 核对无多余改动。
2. 回归门禁：`./gradlew allTests`。
3. 本地预演：`./gradlew publishToMavenLocal -Psigning.skip=true`，抽查生成 POM 与 1.0.4 一致（developers 仅 zusrsoft、坐标正确、模块间依赖同为 io.github.zusrsoft）。
4. 正式发布：`./gradlew publishAllPublicationsToMavenCentralRepository --no-configuration-cache`（约 15 分钟；发布期间不并行上传同版本）。
5. 确认：Portal API 查 PUBLISHED → repo1 抽查 `io/github/zusrsoft/diagram-*/1.0.5/` 目录与 POM。
6. tag `release-1.0.5` 指向发布提交；**推送前与用户再次确认**。

## 5. 验收标准

- repo1 上 `diagram-core / diagram-layout / diagram-parser / diagram-render` 的 1.0.5 全平台构件可下载。
- 仓库根存在 LICENSE；README 双语署名段正确；两份 README 无残留 `1.0.4` 引用。
- 生成的 1.0.5 POM 与 1.0.4 POM 逐字节等价（除 version 外）。
- `git status` 干净（p0-repo-out 已忽略）；存在 tag `release-1.0.5`。
